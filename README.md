# Hello CLI

A simple command line tool that greets you.

## Installation

```bash
pip install -e .
```

Or just run directly:

```bash
python hello.py <name>
```

## Usage

```bash
python hello.py World
# Output: Hello, World!

python hello.py Alice
# Output: Hello, Alice!
```

## Testing

```bash
python -m pytest -q
```
