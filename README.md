# Hello CLI

A simple command line tool that greets you.

## Installation

```bash
pip install -e .
```

Or just run directly:

```bash
python hello.py <name>
```

## Usage

```bash
python hello.py World
# Output: Hello, World!

python hello.py Alice
# Output: Hello, Alice!
```

## Testing

```bash
python -m pytest -q
```

## Demo Scripts

Run the demo hello script:

```bash
bash scripts/hello.sh
# Output: hello claw

bash scripts/hello2.sh
# Output: hello claw 2
```
